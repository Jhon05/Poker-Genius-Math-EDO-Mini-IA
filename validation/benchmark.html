1. Comprobar y activar

La activación autoriza descargar el runtime, la biblioteca WASM y los pesos externos. Los modelos y sus tamaños son candidatos, no una selección pedagógica validada. La primera descarga puede ser grande.

2. Benchmark por etapas

B requiere el JSON de A revisado por una persona; C requiere B. Un resultado del mismo modelo evaluándose a sí mismo no aprueba la etapa. Lee la rúbrica y usa el formulario de revisión humana para puntuar las transcripciones. Cargar un archivo no cambia el modelo ni la nota.



3. Caché: dos ejecuciones separadas
Guarda la primera ejecución. Recarga esta página, elige el mismo candidato, vuelve a activarlo y compara. No basta con que la segunda carga sea más rápida. El JSON conserva el indicador del runtime y las solicitudes de pesos observadas.
  
Repetir un arranque realmente frío
Esta acción borra solo los recursos del modelo activo mediante la API de WebLLM. No borra informes, partidas ni chats. Necesita el runtime ya preparado.


4. Worker, cancelación y recuperación
Se genera una respuesta larga real, se pulsa una interacción visual durante la espera, se cancela y se intenta otra consulta. Cuando la generación termina antes de cancelar, la prueba queda inconclusa, no aprobada.
  


Alcance de la evidencia
